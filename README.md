## Highlighted Projects

### `course-rating-app/`
A mobile Android app that helps students filter and compare UIUC courses by rating categories. Built in Java using Android Studio. Includes server communication and JSON-based data serialization.

### `gradebuddy/`
A web app to track grades, set academic goals, and receive tailored feedback. Features a clean UI built with Tailwind CSS and JavaScript. Authentication and grade data are securely handled with Django and PostgreSQL.

### `restaurant-diary/`
A full-stack web journal to log restaurant experiences (ratings, photos, notes). Built with React, FastAPI (Python), and Tailwind CSS. Implements secure data submission via Pydantic models and REST APIs.

### `movie-favorites/`
A React-based app that fetches popular movies using the TMDB API. Users can search, favorite/unfavorite, and view selected titles. Uses Context API for state management and `localStorage` for persistent favorites.

## Algorithmic + Systems Projects

These projects demonstrate my understanding of data structures, algorithms, memory management, and C++:

- `linked-lists/`: Custom implementation of singly and doubly linked lists with memory-safe deletion.
- `mazes/`: Recursive maze generation and pathfinding.
- `mountain-paths-finder/`: Highlights least-elevation-gain paths on a grid using greedy algorithms.
- `image-seam-carving/`: Implements seam carving to reduce image width while preserving content.
- `puzzle/`, `stickers/`, `mosaics/`: Problem-of-the-day style C++ exercises to reinforce STL, recursion, and tree structures.
